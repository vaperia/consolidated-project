# Adaptive Portfolio

Use one website and change the URL for different applications.

Examples after GitHub Pages is enabled:

- `https://vaperia.github.io/school-consolidated-project/?role=general`
- `https://vaperia.github.io/school-consolidated-project/?role=software`
- `https://vaperia.github.io/school-consolidated-project/?role=backend`
- `https://vaperia.github.io/school-consolidated-project/?role=frontend`
- `https://vaperia.github.io/school-consolidated-project/?role=embedded`
- `https://vaperia.github.io/school-consolidated-project/?role=robotics`

The URL changes the headline, emphasized skills, featured projects and ordering while keeping all projects available.

## Personal projects

Trading Journal and Hobby Carousel are already included in `portfolio.js`, but their `source` links are currently `#` placeholders. Replace those with the GitHub links after you add the projects to your consolidated repository.
